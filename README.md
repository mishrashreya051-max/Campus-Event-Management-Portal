# Campus-Event-Management-Portal
The Organizer Dashboard helps event organizers create, manage, publish and monitor campus events. It provides an easy way to manage participant registrations and event capacity.

# Features
- Create new campus events using event forms.
- Edit existing event details.
- Publish and unpublish campus events.
- Delete events from the dashboard.
- View all events in an organized dashboard.
- Filter events by category such as Dance, Music, Dramatics, Literary, Fine Arts and Gaming.
- View participant lists for individual events.
- Monitor total events, published events and draft events.
- Track team registrations and total participants.
- Display event registration capacity and availability.
- Prevent event capacity from being reduced below the number of existing registrations.

# Built with

- HTML5 – Creates the structure of the Organizer Dashboard.
- CSS – Provides styling, layouts, tables and responsive design.
- JavaScript – Handles event management, category filtering, form interactions and validation.

# Project Files
- index.html – Main HTML structure of the Organizer Dashboard.
- style.css – Styling and visual design of the dashboard.
- script.js – JavaScript functionality and event management operations.

README.md – Project documentation.

# How to Run
- Download or clone the repository.
- Open the project folder.
- Locate index.html.
- Open it in a web browser.
